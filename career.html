01 / Career Architecture

Find your security track.

Pick an area that interests you. The paths overlap at the fundamentals, but each develops a different technical mindset.

01
Offensive

Offensive Security

Discover and validate weaknesses through authorized security testing, from reconnaissance to professional reporting.

+ Networking & Linux
+ Recon & Enumeration
+ Web Application Security
+ Vulnerability Assessment
+ Penetration Testing
02
Defensive

Defensive Security

Monitor environments, investigate suspicious activity, improve detections, and respond to security incidents.

+ Networking Fundamentals
+ Log Analysis
+ SIEM Concepts
+ Detection Engineering
+ Incident Response
03
Application

Web App Security

Specialize in websites and APIs, with a focus on authentication, access control, application behavior, and secure development.

+ HTTP & Web Architecture
+ Burp Suite Workflow
+ Authentication & Sessions
+ Access Control
+ Secure Code Review
04
Cloud

Cloud Security

Secure cloud environments by understanding identity, permissions, workloads, network boundaries, secrets, and monitoring.

+ IAM & Permissions
+ Cloud Networking
+ Containers & Workloads
+ Secrets Management
+ Cloud Monitoring
05
Investigation

DFIR & Forensics

Investigate incidents, analyze digital artifacts, reconstruct attacker activity, and communicate technical findings.

+ Digital Evidence
+ Windows & Linux Artifacts
+ Timeline Analysis
+ Malware Triage
+ Incident Investigation
06
Engineering

Security Engineering

Combine software, infrastructure, automation, and security to build reliable security controls and tooling.

+ Python & Automation
+ Systems & Networking
+ Security Architecture
+ DevSecOps
+ Security Tooling

Threats, vulnerabilities, risk, controls, detection and defense.
